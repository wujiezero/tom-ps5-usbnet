# tom-ps5-usbnet

给 PS5 插上 USB 万兆网卡，插件会用网卡自己的 IP 开一个网页，在电脑或手机浏览器里就能管理主机上的文件。不插网卡也能用，走主机自带网络。

## 功能

- 管理内置存储、M.2 扩展硬盘和外接 USB 硬盘
- 上传、下载（文件夹打包成 tar）、复制、移动、重命名、删除、新建文件夹
- 拖进文件或文件夹就能上传，有进度条、百分比和实时速度
- 电脑和主机上开着的页面会同步显示传输进度
- 主屏幕图标，点开就用主机浏览器打开页面
- 手动硬盘测速
- 连接 NAS（SMB），浏览共享文件夹，把文件或文件夹直接拷到内置存储、M.2 或外接硬盘
- 端口转发：用网卡的 IP 访问主机上其他插件的端口，比如 FTP、ELF 加载器
- 没有能用的 USB 网卡时走主机自带网络，文件管理和 NAS 照样能用
- 网卡插着但网线没插、中途拔掉或拿不到 IP 时，自动改走主机自带网络，网线接回后自动切回网卡
- 退出时还原网卡、关掉端口

## 已适配的网卡

| 芯片 | USB ID | 速率 | 状态 |
| --- | --- | --- | --- |
| Realtek RTL8159 | `0bda:815a` | 1G/2.5G/5G/10Gbps | 已实测 |
| Realtek RTL8156B / RTL8156BG | `0bda:8156` | 1G/2.5Gbps | 已实测（2.5G） |
| Realtek RTL8157 | `0bda:8157` | 1G/2.5G/5Gbps | 已实测（5G） |

初代 RTL8156（不带 B）和改过 USB ID 的贴牌网卡还不支持。检测不到能用的网卡时，插件会改走主机自带网络（见下面「不插网卡使用」）。

测试机器：PS5 Slim CFI-2200 B01，系统 12.40。别的机型和系统版本没测过。

## 实测速度

RTL8159，万兆链路：

| 项目 | 速度 |
| --- | --- |
| TCP 上传 | 约 3.2 Gbit/s |
| TCP 下载 | 约 3.0 Gbit/s |
| 实际上传到 M.2 硬盘 | 约 370–440 MB/s |

链路虽然协商到 10 Gbps，实际跑不到这么快，因为网卡驱动跑在用户态，受 USB 传输方式限制。

RTL8156B 在 2.5G 链路下，上传到扩展存储约 141 MB/s。RTL8157 在 5G 链路下，上传到扩展存储约 124 MB/s。

连续写大文件时，测试用的 M.2 和 USB 硬盘都出现过中途掉速。掉速时硬盘满载、网络空闲，所以是卡在硬盘写入上，具体原因还没查清。

## 使用

1. 把网卡插到 PS5 的 USB 口，接好网线。
2. 用你的 ELF 加载器发送 `tom-ps5-usbnet.elf`。
3. 主机弹出 `http://<IP>/` 的通知后，在同一局域网的电脑或手机浏览器里打开。
4. 想要主屏幕图标，点页面顶部的「图标」。主机重启后要重新运行插件。
5. 用完点「退出」。下次用之前把网卡拔插一次。

### 不插网卡使用

没插网卡，或插的网卡不支持时，插件会弹出「未找到可用的 USB 网卡，使用主机网络」，然后在主机自带网络上开 9190 端口。浏览器打开 `http://<主机 IP>:9190/` 就行，主机 IP 在网络设置里能看到。速度取决于主机自带网口或 Wi-Fi。主机待机再唤醒后，插件会自动重新开端口。

### 网线没插或中途拔掉

插着网卡但网线没插（或运行中拔掉了网线、网卡拿不到 IP），插件不会退出：会弹出「网线未连接，改用主机网络：http://<主机 IP>:9190/」，在主机自带网络上开 9190 端口。网线接回、网卡拿到 IP 后，弹出「网卡已恢复，切回网卡：http://<网卡 IP>/」，页面回到网卡上。

- 电脑上开着的页面会自动跳到能用的地址；有上传、下载等传输在进行时，等传完再跳。
- 网线拔掉后约 3 秒才切到主机网络，免得网线接触不良时来回切换。网卡恢复后，主机网络上的 9190 端口还会多开约 15 秒、等没有连接了才关，给开着的页面留时间跳回去。
- 启动时没插网线，要先等约 15 秒确认网线没接，再切到主机网络。
- 主机自带网口和 Wi-Fi 都没连网时没有地址可切，插件会一直等网线接回。
- 网线断开期间端口转发用不了，网卡恢复后自动接着转发。

### 从 NAS 复制

1. 打开页面上的「NAS」，点「添加 NAS」，填地址（IP 或主机名）、用户名和密码。用户名留空就是来宾登录。
2. 点进共享文件夹，勾选要拷的文件或文件夹，点「复制到主机」，选好目标位置。
3. 进度在页面底部，可以随时取消。失败或取消时，拷了一半的内容会被删掉。

支持 SMB 2/3（Windows 共享、群晖、威联通、Samba 等）。现在只能从 NAS 拷到主机，目标位置有同名项目时不会覆盖。插着 USB 网卡时先用网卡连 NAS，连不上再走主机自带网络，页面底部会显示走的哪条线路。NAS 拷贝速度还没实测过。

### 端口转发

主机上其他插件（FTP、ELF 加载器等）的端口，本来只能从主机自带网口或 Wi-Fi 的 IP 访问。打开页面上的「端口转发」，开着的端口用网卡的 IP 也能访问，比如 `ftp://<网卡 IP>:2121`，主机自带网口和 Wi-Fi 可以不接。

插件预设了常见开源插件的默认端口，第一次运行时全部开着：

| 端口 | 用途 |
| --- | --- |
| 9021 | ELF 加载器（elfldr / etaHEN） |
| 9020 | ELF 加载器（漏洞自带） |
| 2121 | FTP（ftpsrv） |
| 1337 | FTP（etaHEN） |
| 9090、12800 | PKG 直接安装（etaHEN） |
| 9081 | 内核日志（etaHEN） |
| 3232 | 内核日志（klogsrv） |
| 8080 | 网页（websrv） |
| 2323 | Shell（shsrv） |
| 2159 | GDB（gdbsrv） |

也可以自己添加、修改、停用或删除，网卡端口和主机端口可以不同，最多 32 个。设置存在 `/data/tom-ps5-usbnet/forward.txt`，改完马上生效。

- 只转发 TCP。UDP 和靠局域网广播自动找主机的功能过不来。
- FTP 要用被动模式（PASV / EPSV，多数客户端默认就是）。插件会把服务器回复里的地址改成网卡的 IP。主动模式（PORT）不支持。
- 被转发的服务看到的来源地址都是 127.0.0.1。
- 网卡端口 80 是本页面，主机端口 9190 是插件自己用的，这两个不能填。
- 不插网卡时用不上转发，主机 IP 本来就能直接访问这些端口。

运行日志在 `/data/tom-ps5-usbnet/log.txt`，上一次的在 `log.old.txt`。每行开头是启动后的秒数。日志不记录序列号、MAC 地址、IP 地址和文件名。

## 注意事项

- **页面没有登录。** 能访问这个端口的人都能读、删主机上的文件，也能用保存的 NAS 账号浏览 NAS、往主机拷文件。只在信得过的局域网里用，别映射到公网。
- 端口转发同样没有登录：开着的端口，局域网里谁都能通过网卡的 IP 连上。
- NAS 密码加密后存在主机的 `/data/tom-ps5-usbnet/nas.txt`，密钥由这台主机算出、不落盘，文件拷到别的主机或电脑上解不开，页面上也不会再显示。0.2 版存下的明文密码，第一次打开「NAS」时会自动改成加密保存。不想存密码，可以在 NAS 上开一个只读的来宾共享。
- 插件运行时别拔网卡。
- 别和其他占用同一块网卡的程序一起运行。

## 构建

需要 Python 3。`scripts/prepare.py` 默认下载 Apple Silicon macOS 版的 Zig；其他系统请改 `SPECS` 里的地址和校验值。

```bash
make prepare
```

```bash
make test
```

```bash
make ps5
```

输出在 `build-ps5/tom-ps5-usbnet.elf`。
