使用说明

  • 访问地址是“USB 网卡的 IP + 网卡端口”。默认连到主机上的同一端口，也可以为每一项另设主机端口。
  • 只转发 TCP。UDP 服务，以及靠局域网广播自动搜索主机的功能，无法经过 USB 网卡。
  • FTP 请使用被动模式（PASV / EPSV，多数客户端默认如此），插件会把服务器回复中的地址改为 USB 网卡的地址。主动模式（PORT）不受支持。
  • 被转发的服务看到的来源地址都是 127.0.0.1。有些服务会信任本机连接，请留意。
  • 网卡端口 80 是本页面，主机端口 9190 是插件自己的本机端口，二者不能使用。
  • 端口转发和本页面一样没有登录，只应在可信的局域网中使用。

tom-ps5-usbnet

版本 —

tom-ps5-usbnet 是一款 PS5 插件。插上 USB 有线网卡后，插件以网卡自己的 IP 地址提供本网页，在同一局域网的电脑或手机浏览器中即可管理主机上的文件。未插网卡时，插件改用主机自带网络。

功能支持的网卡使用方法不插网卡从 NAS 复制端口转发注意事项风险提示许可与致谢

功能

  • 管理内置存储、M.2 扩展硬盘和外接 USB 硬盘。
  • 上传、下载（文件夹打包为 tar）、复制、移动、重命名、删除和新建文件夹。
  • 拖入文件或文件夹即可上传，显示进度、百分比和实时速度；各浏览器页面同步显示传输进度。
  • 主屏幕图标：点开后用主机浏览器打开本页。
  • 手动硬盘测速。
  • 连接 NAS（SMB），浏览共享文件夹，并将文件或文件夹直接复制到主机存储。
  • 端口转发：通过 USB 网卡的地址访问主机上其他插件的端口。
  • 没有可用的 USB 网卡时改用主机自带网络，文件管理和 NAS 功能照常可用。
  • 退出时还原网卡并关闭端口。

初代 RTL8156（不带 B）以及修改过 USB ID 的贴牌网卡暂不支持。测试机型为 PS5 Slim CFI-2200 B01，系统版本 12.40，其他机型和系统版本尚未测试。

实测速度（RTL8159，万兆链路）：TCP 上传约 3.2 Gbit/s，下载约 3.0 Gbit/s，上传到 M.2 硬盘约 370–440 MB/s；RTL8156B 在 2.5G 链路下上传到扩展存储约 141 MB/s；RTL8157 在 5G 链路下约 124 MB/s。网卡驱动运行在用户态，受 USB 传输方式限制，达不到链路的标称速率。

使用方法

  1. 将网卡插入 PS5 的 USB 接口，并接好网线。
  2. 用 ELF 加载器发送 tom-ps5-usbnet.elf。
  3. 主机弹出 http://<IP>/ 通知后，在同一局域网的电脑或手机浏览器中打开该地址。
  4. 需要主屏幕图标时，点击页面顶部的“图标”。主机重启后需重新运行插件。
  5. 使用完毕点击“退出”。下次使用前，请将网卡拔插一次。

不插网卡使用

未插网卡或网卡不受支持时，插件提示“未找到可用的 USB 网卡，使用主机网络”，并在主机自带网络上开放 9190 端口。在浏览器中打开 http://<主机 IP>:9190/ 即可，主机 IP 可在网络设置中查看。此时速度取决于主机自带网口或 Wi-Fi。主机待机后再唤醒，插件会自动重新开放端口。

从 NAS 复制

  1. 打开“NAS”页，点击“添加 NAS”，填写地址（IP 或主机名）、用户名和密码。用户名留空即为来宾登录。
  2. 进入共享文件夹，勾选要复制的文件或文件夹，点击“复制到主机”并选择目标位置。
  3. 进度显示在传输面板中，可随时取消。失败或取消时，已复制的部分内容会被删除。

支持 SMB 2/3（Windows 共享、群晖、威联通、Samba 等）。目前只能从 NAS 复制到主机，目标位置存在同名项目时不会覆盖。插着 USB 网卡时优先经网卡连接 NAS，连接不上再改用主机自带网络。

端口转发

主机上其他插件（如 FTP 服务器、ELF 加载器）的端口只能经主机自带网卡访问。在“端口转发”页启用相应端口后，即可用 USB 网卡的 IP 访问，自带网口和 Wi-Fi 可以不接。插件预设了常见开源插件的默认端口，也可以自行添加。仅支持 TCP，FTP 需使用被动模式。

注意事项

  • 本页面没有登录。能访问该端口的人都可以读取、删除主机上的文件，也能使用已保存的 NAS 账号。请只在可信的局域网中使用，不要映射到公网。
  • NAS 密码加密后保存在主机的 /data/tom-ps5-usbnet/nas.txt，密钥由本机计算得出且不写入磁盘，文件复制到其他主机或电脑上无法解开，页面也不会再显示密码。
  • 插件运行时请勿拔出网卡，也不要与其他占用同一块网卡的程序同时运行。
  • 运行日志位于 /data/tom-ps5-usbnet/log.txt，上一次的日志为 log.old.txt。日志不记录序列号、MAC 地址、IP 地址和文件名。

风险提示

本插件以非官方方式在 PS5 上运行，直接操作 USB 设备和存储。开发测试期间曾出现主机断电重启、外接硬盘盒和网卡掉线等情况，原因尚未完全查明。使用过程中可能丢失数据，主机或硬件也可能出现问题，请提前备份重要数据。
